# 🎨 Neo's Product Workbook

Hi Neo! This isn't just a coding project — **you're the product designer.**

A product designer is the person who decides **what** to build, **who** it's for,
and **how it should feel**. You make the big decisions. When it's time to actually
build something, you tell **Claude** what you want, and Claude writes the code
with you. You design — Claude builds. Together you make it real. 🚀

## 🔁 The design loop

This is how real product designers work. Go around and around:

```
   IMAGINE  →  DESCRIBE  →  BUILD (with Claude)  →  TRY IT  →  IMPROVE
      ↑                                                            │
      └────────────────────────────────────────────────────────────┘
```

1. **Imagine** — picture something that would make Bookaroo better.
2. **Describe** — write it down in plain words (see the examples below).
3. **Build** — tell Claude your idea; Claude helps write the code.
4. **Try it** — use it like a real kid would. Does it feel right?
5. **Improve** — what's still clunky? Go round again.

---

## 🧠 The big questions (answer these in your head, or write them down)

A good product designer can answer these about their product:

- **Who is it for?** (Kids in your class? The whole school?)
- **What problem does it solve?** (Why would someone use it instead of just... not?)
- **What are the 3 most important things** a person can do with it?
- **How should it feel?** (Cosy? Fun? Fast? Calm?)
- **What should it be called?** (You picked "Bookaroo" — does it still feel right as it grows?)

There are no wrong answers. These are *your* calls to make.

---

## 💬 How to ask Claude to build something

The trick is to describe **what you want** and **why**, not how to code it.
Claude figures out the code. Here are good examples:

> "I want each book to show a little tag that says **Available** or **Swapped**,
> so kids know which ones are still free."

> "Can we add a page that shows **only my books**, so I can see what I'm offering?"

> "When someone adds a book, I want a **happy message** to pop up that says
> 'Added to the shelf!'"

> "I want to be able to **search** for a book by typing its name."

> "Make the cards look more like **real book spines** on a shelf."

See how each one is a *design idea*, described simply? That's your job. 🎯

## 🧪 Test with real people

The best designers watch real people use their product. When you build
something new:

- Let a friend or Dad use it **without helping them**.
- Watch where they get confused or stuck.
- That confusion is **gold** — it tells you exactly what to improve.
